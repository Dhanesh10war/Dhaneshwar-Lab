## Engineering Architecture

The platform is engineered using modern web technologies:

- **Frontend Core**: React 19, TypeScript, Vite
- **Styling & Design System**: Tailwind CSS v4, Custom Motion Tokens
- **3D Spatial Computing**: Three.js (WebGLRenderer, ACESFilmic Tone Mapping, throttled rendering loop)
- **Kinetic & Scroll Orchestration**: GSAP with ScrollTrigger (pinned narrative storytelling)
- **Smooth Scrolling**: Lenis synchronized with the GSAP ticker
- **Component Transitions**: Framer Motion
- **Iconography**: Lucide React (strict semantic vector icon registry)
- **Accessibility**: Full compliance with prefers-reduced-motion, semantic navigation, and keyboard accessibility

## Local Development

### Prerequisites

- Node.js (v18 or newer recommended)
- npm or pnpm

### Getting Started

1. Clone or navigate to the project directory:
   ```bash
   cd "Dhaneshwar Portfolio"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```
